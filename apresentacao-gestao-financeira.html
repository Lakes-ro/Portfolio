Gestão Financeira (MentorFin)

Plataforma que une a precisão contábil à agilidade do desenvolvimento web moderno. Um motor de IA classifica as transações automaticamente e gera indicadores em tempo real, para que o cliente veja a saúde financeira do negócio sem precisar organizar planilha nenhuma.

O que o sistema faz

O MentorFin é o painel que o administrador usa para acompanhar a saúde financeira de vários clientes ao mesmo tempo. Cada cliente tem seu próprio dashboard, com status de "Saudável" ou "Sem dados" calculado a partir das transações lançadas — e todo o resto da rotina contábil do dia a dia (categorias, metas, planejamento e razonete) vive dentro do mesmo painel.

Clientes

Cadastro e organização de cada cliente atendido pela plataforma, com acesso individual ao próprio dashboard.

Categorias

Estrutura de categorias que sustenta a classificação automática das transações feita pela IA.

Dashboards

Visão em tempo real da saúde financeira de cada cliente, com indicadores de status à primeira vista.

Metas

Definição de metas financeiras por cliente, para acompanhar progresso ao longo do tempo.

Planejamentos

Planejamento financeiro estruturado, servindo de referência para comparar previsto x realizado.

Razonete

Livro-razão em formato de T (razonete), a mesma lógica contábil clássica, só que digital e automatizada.

Como foi construído

Arquitetura enxuta, pensada para ser rápida de carregar e barata de manter — sem framework pesado no front-end e sem servidor próprio para administrar.

Supabase Banco de dados, autenticação e API em tempo real
Vanilla JavaScript Interface leve, sem framework, focada em performance
IA para classificação Categoriza transações automaticamente a partir dos lançamentos
Login por cliente Cada cliente só enxerga os próprios dados
